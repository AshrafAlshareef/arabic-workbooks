# كتاب القصص المصورة

كتاب **قصص مصورة قصيرة** للطلاب المبتدئين، يُبنى من الصفر بصيغة **DOCX** بخط عربي
واتجاه من اليمين لليسار، بمقاس **A5**.

كل قصة في **صفحة واحدة**: عنوان، صورة، وثلاث جمل قصيرة. القصص هي نفسها الـ **28** كلمة
المستخدمة في بقية كتب هذا المشروع (`Arabic_Alphabet_Workbook`،
`Arabic_Harakat_Workbook`، `Arabic_Word_Analysis_Workbook`) وبنفس الترتيب،
ليتدرّب التلميذ على المفردات نفسها.

> **مهم:** هذا المشروع **مستقل** ولا يتصل بسكربتات الجذر
> (`build-all.bat` / `docx-to-pdf.ps1` / `merge-pdfs.js`) — تعديلها خارج نطاق العمل.

| صفحة الغلاف | 1 |

## بنية الكتاب

### صفحة الغلاف
- صورة `assets/coverpage.png` بمقاس صفحة A5 كاملة (**full-bleed**) بلا هوامش
- **بدون** ترقيم صفحات ولا تذييل
- تُبحث عن الصورة بالترتيب: `assets/coverpage.png` ← `../covers-and-photos/cover-arabic.png`
- القسم يُبنى بهوامش صفر، والصورة تُكبَّر عمداً وتُوسَّط ليخرج ما زاد عن الصفحة
  فتغطي الحواف الأربع

### صفحة عنوان الكتاب
- عنوان الكتاب `كتاب القصص المصورة`، خط Traditional Arabic، لون `1B4965`، 48pt
- سطر وصفي `هيا بنا نقرأ القصص` بلون `2E86AB`، 24pt
- فاصل أفقي تحت العنوان بلون `34495E`

### صفحة القصة
كل قصة **قسم مستقل** (section) مستقل، فلا تنتقل صفحة إلى أخرى:

| العنصر | المحتوى | الحجم / اللون |
|--------|---------|---------------|
| **العنوان** | عنوان القصة، **ليس عريضاً**، في الوسط، RTL | 24pt، `1B4965` |
| **الصورة** | داخل إطار رقيق، في الوسط، محتواة في صندوق 3:2 بعرض 112 مم | حدود `34495E` |
| **الجمل** | ثلاث جمل، كل جملة فقرة مستقلة في الوسط، RTL | 20pt، `1B4965`، تباعد أسطر `AT_LEAST` 24pt |

> **ملاحظة:** العنوان **غير عريض** عمداً، وبلون واحد بلا خط فاصل تحته، حتى يبقى
> هادئاً لا ينافس الصورة. وهو يتكوّن من **3 إلى 5 كلمات** (بحد أقصى 5).

## مصدر البيانات

المحتوى مستخرج من `source.docx` بواسطة `extract-from-source.js`، الذي يحوّله إلى:

| الملف | الوصف |
|-------|-------|
| `assets/stories.json` | فهرس القصص **بترتيبها** (28 مدخلاً) + بيانات الكتاب |
| `assets/texts/01-asad.txt` … | عنوان القصة في السطر الأول، ثم جملها الثلاث |
| `assets/images/01-asad.jpg` … | صورة القصة، 28 صورة |
| `assets/coverpage.png` | غلاف الكتاب |

صيغة ملف النص (UTF-8 بلا BOM، أسطر `\n`):

```
أَسَدٌ في الغَابَةِ
رأى أَحمدُ أَسَدًا جميلًا في الغابة.
كان الأَسَدُ يمشي بين الأشجار بثقة.
ابتسم أَحمدُ وقال: ما أقوى هذا الأَسَد!
```

صيغة `stories.json`:

```json
{
  "book": { "title": "…", "subtitle": "…", "cover": "coverpage.png" },
  "stories": [
    { "id": 1, "letter": "أ", "word": "أَسَد", "title": "أَسَدٌ في الغَابَةِ",
      "text": "texts/01-asad.txt", "image": "images/01-asad.jpg" }
  ]
}
```

> `create-workbook.js` يقرأ **هذا المجلد فقط** ولا يعرف شيئاً عن `source.docx`،
> ولا يحتوي أي نص قصة مكتوب داخله.

### peculiarities في `source.docx` يتعامل معها المستخرِج

| الملاحظة | المعالجة |
|----------|----------|
| صورة القصة 7 (زرافة) مُثبَّتة **داخل فقرة العنوان** | تُسند الصور بترتيب ورودها في المستند لا بربطها بالفقرات |
| عنوان القصة 21 (شمس) **ملتصق** بنهاية جمل القصة 20 (رجل) | يُفصل العنوان الملتصق ويُخزَّن عنواناً مستقلاً |
| فقرة فارغة تحمل `outlineLvl` (بعد القصة 15) | تُتجاهل |
| `هـ — هلال` فيها **تطويل** `U+0640` | النمط يقبل التطويل |
| داخل `w:drawing` نصّ تخطيط (`right`، `561191`) | كتل `w:drawing` / `w:pict` تُحذف قبل استخراج النص |

## الصور

- تُقرأ من `assets/images/` وتُدرج مباشرة بصيغة JPEG (`type: "jpg"`)
- **لا يُكبَّر** أي صورة: العرض الأقصى 800 بكسل، والارتفاع يتبع النسبة
- تُصغَّر الصور في خطوة الاستخراج لا في خطوة البناء: **14.81 MB ← 4.02 MB**
- النسبة الأصلية **3:2** لكل الصور وهي محفوظة
- `fitImage()` تقرأ أبعاد JPEG من ترويسة `SOF` (`getJpegDimensions`)، لأن
  `getPngDimensions` في الكتب المجاورة يقرأ PNG فقط
- إن فشلت قراءة أي صورة يُبنى القسم بدونها مع رسالة تحذير

### ترقيم الصفحات

مُعطَّل الآن، لكنه **مُنفَّذ بالكامل** خلف علم واحد في أعلى `create-workbook.js`،
بنفس طريقة `Arabic_Alphabet_Workbook`:

```js
// Set to false to hide the page number footer (Arabic_Alphabet_Workbook style).
const SHOW_PAGE_NUMBERS = false;
```

 تحويله إلى `true` يُظهر رقم الصفحة في المنتصف في كل صفحة **عدا الغلاف**.

### اتجاه النص RTL

يُضبط على مستوى الفقرة بـ `bidirectional: true` (وهي الخاصية التي تُخرج
`<w:bidi/>` في `docx` 9.7.x).

> **ملاحظة:** الخاصية `direction: "RTL"` المستخدمة في الكتب المجاورة **لا تفعل شيئاً**
> في `docx` 9.7.x — لا وجود لها في `ISectionPropertiesOptions`، فتُتجاهل بصمت.
> والنتيجة العملية لم تتأثر هناك لأن محارف العربية تُرسم من اليمين لليسار بطبيعتها،
> لكن هذا المشروع يستخدم `bidirectional: true` صراحةً.

## الثوابت القابلة للتخصيص

الأبعاد في `create-workbook.js` مضبوطة بالتويب (twip = 1/20 نقطة) لضمان استقرار التخطيط:

| الثابت | القيمة | الوظيفة |
|--------|--------|---------|
| `SHOW_PAGE_NUMBERS` | `false` | إظهار/إخفاء ترقيم الصفحات |
| `A5_WIDTH` / `A5_HEIGHT` | 5.83 / 8.27 بوصة | مقاس الصفحة |
| `MARGIN_TOP` / `MARGIN_BOTTOM` | 0.35 بوصة | هوامش أعلى وأسفل |
| `MARGIN_SIDE` | 0.5 بوصة | الهامش الجانبي |
| `CONTENT_WIDTH` | 6955 تويب (~122.6 مم) | عرض منطقة المحتوى |
| `TITLE_SIZE` | `48` (**24pt**) | عنوان القصة — العناوين 3–5 كلمات، وفيه سطر واحد |
| `SENTENCE_SIZE` | `40` (**20pt**) | حجم جمل القصة |
| `SENTENCE_LINE` | `480` تويب | ارتفاع سطر الجملة (`AT_LEAST` 24pt) |
| `SENTENCE_AFTER` | `120` تويب | الفاصل بين الجمل |
| `TITLE_AFTER` | `200` تويب | الفاصل تحت العنوان |
| `IMAGE_BOX_PX` | ~423 بكسل (112 مم) | عرض صندوق الصورة |
| `IMAGE_BOX_RATIO` | `3 / 2` | نسبة الصورة المستهدفة |
| `TITLE_PAGE_SIZE` | `96` (**48pt**) | عنوان الكتاب في صفحة العنوان |

> **وحدات حجم الخط:** قيم `docx` بالنقاط **الأنصاف** (half-points)، فـ `48` تعني
> **24pt** وليس 48pt. وهذا أيضاً لأطوال الخانات في Word: `WidthType.DXA` يعني 1/20 من النقطة،
> و`TWIPS_PER_PX = 15` (1 بكسل عند 96dpi = 1/96 بوصة).

> **ملاحظة على `TITLE_SIZE`:** العنوان سطر واحد **غير عريض**. لو لُفّ إلى سطرين
> فالنتيجة تبقى سليمة لأن ارتفاع السطر `AT_LEAST` يسمح بالتمدد، وقد قِيست الصفحات
> بـ Word فلم يفيض أي قسم على صفحة إضافية (30 صفحة بالضبط).

## ثوابت الصور في خطوة الاستخراج

| الثابت في `extract-from-source.js` | القيمة | الوظيفة |
|-----------------------------------|--------|---------|
| `MAX_IMAGE_WIDTH` | `800` بكسل | العرض الأقصى للصورة (لا تكبير) |
| `JPEG_QUALITY` | `70` | جودة إعادة الترميز |
| `COVER_WIDTH` / `COVER_HEIGHT` | `1024` / `1536` | مقاس الغلاف المؤقت |
| `COVER_COLOR` | `0x1b4965ff` | لون الغلاف المؤقت |
| `EXPECTED_SENTENCES` | `3` | عدد الجمل المطلوب لكل قصة |
| `MAX_TITLE_WORDS` | `5` | أقصى عدد كلمات في العنوان |

> **تحذير مهم:** يجب ضبط الجودة على النسخة نفسها:
> `image.quality(70)` ثم `getBufferAsync(...)`. تمرير `{ quality }` إلى
> `getBufferAsync` **مُتجاهَل** فينتج ملفات أكبر بنحو 20 ضعفاً.

## ملاحظات تقنية

### قبل التشغيل
- أغلق Microsoft Word أولاً لتجنّب خطأ «الملف قيد الاستخدام».
- تأكد من وجود خط **Traditional Arabic** على النظام، وإلا ظهر النص بخط بديل.

### الغلاف المؤقت
`assets/coverpage.png` **مؤقت**: صورة 1024×1536 بلون `1B4965` صلب **بلا أي نص**،
وُلِّدت مرة واحدة. الغلاف الحقيقي يُوضع مكانه باستبدال الملف، ثم
`npm run build`، فيكتشف البناءُ الملفَ الجديد ويُدرج الغلاف الصحيح تلقائياً.
> السكربت **لا يستبدل** الغلاف الموجود أبداً عند إعادة التشغيل.
>
> وخدمة `loadCover()` تطبع تحذيراً بوجود الغلاف المؤقت.

### التخصيص
- **تعديل عنوان أي قصة:** عدّل حقل `title` في مصفوفة `STORIES` (أعلى
  `extract-from-source.js`) ثم `npm run extract && npm run build`.
  تُكتب العناوين في ملفات `texts/*.txt` و`stories.json` معاً.
- **تعديل اسم الكتاب:** عدّل `BOOK` في نفس الملف.
- **تعديل الجمل أو إضافة قصة:** عدّل ملفات `assets/texts/*.txt` و`stories.json`
  مباشرة ثم `npm run build` — لا حاجة لإعادة الاستخراج.
- **ألوان وحدود:** الثوابت `COLOR_*` أعلى `create-workbook.js`.

## English

An **illustrated short-story book** for young beginners: 28 one-page stories (title, image,
three short sentences), built as a right-to-left **DOCX** (A5) and converted to **PDF** with
Word. The stories use the same 28 words, in the same order, as the rest of the project.

> This project is **standalone** and is not wired into the root scripts
> (`build-all.bat` / `docx-to-pdf.ps1` / `merge-pdfs.js`).

### Output

| File | Description |
|------|-------------|
| `Arabic_Stories_Workbook.docx` | final book, written inside the project folder |
| `Arabic_Stories_Workbook.pdf` | PDF version (via the root `build-all.bat`) |

### Page count

| Page | Count |
|------|-------|
| Cover page | 1 |
| Book title page | 1 |
| Story pages (28) | 28 |
| **Total** | **30 pages** |

### Data source

Content is extracted from `source.docx` by `extract-from-source.js` into `assets/`:
`stories.json`, `texts/*.txt` (title + three sentences), `images/*.jpg` (28 images), and
`coverpage.png`. `create-workbook.js` reads only that folder and never touches `source.docx`.

The cover is `assets/coverpage.png`; the shipped file is a **placeholder** (solid `1B4965`,
no text). Replace it and rebuild to use a real cover — the extractor never overwrites an
existing cover.

### Requirements & run

- Node.js 16+
- System font: **Traditional Arabic**

```bash
npm install
npm run build     # or: node create-workbook.js
npm run extract   # regenerate assets/ from source.docx (not needed per build)
```

`jszip` and `jimp` are needed only by the extractor; building needs `docx` alone.

### Customize

- Story sentences: edit `assets/texts/*.txt` and `stories.json`, then `npm run build`
- Story titles / book name: edit `STORIES` / `BOOK` in `extract-from-source.js`, then
  `npm run extract && npm run build`
